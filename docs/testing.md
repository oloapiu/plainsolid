# plainsolid: testing

How the project is tested. The design under test is in [design.md](design.md);
the shared fixtures are the zoo documents ([design.md#the-zoo](design.md#the-zoo)).

## Principles

1. **The file is the truth.** A test that changes state asserts on the file
   text and on the geometry re-evaluated from it, never on memory alone.
2. **The API is the primary test surface.** The client holds no model state.
   Browser tests cover only picking, sketch interaction, layout, highlighting.
3. **Golden numbers over golden images.** Volume, area, bounding box, counts
   and mass properties, through the queries we ship. Images test the renderer.
4. **Every bug becomes a fixture.** A regression test or a zoo change, never
   a one-off.
5. **Everything runs on a Linux CI runner without a display.** The fast
   subset runs locally in under a minute.
6. **Determinism is tested, not assumed.** The same file evaluated twice gives
   the same query results and the same encoded mesh.

## Commands

| Command | Runs |
|---|---|
| `uv run pytest -m "unit or golden or roundtrip or solver"` | the fast subset |
| `uv run pytest` | every pytest layer; `corpus` skips without `corpus/` |
| `uv run pytest -m corpus` | the local corpus only |
| `cd web && npm test` | the client state tests |
| `cd web && node verify.mjs <url> <project>` | the browser suite against a running server (recipe under CI) |
| `uv run python scripts/bench.py` | the performance measurements, compared with the baseline |
| `PLAINSOLID_PERF_STRICT=1 uv run pytest -m perf` | the performance layer with the thirty percent rule |
| `uv run python scripts/generate_edit_types.py --check` | the browser edit types against the engine contract |

## Layers

Every pytest test carries exactly one layer marker, declared in
`pyproject.toml` with `--strict-markers`; `tests/conftest.py` fails
collection on an unmarked test. The L numbers match the test docstrings.

| Layer | Marker | What it covers | Speed |
|---|---|---|---|
| L0 unit | `unit` | DSL parsing and spans, evaluation and feature identity, selectors, edit ops and composition, offsets, planes, sketch ops, mesh encoding, sidecars, the workspace, reliability, request contracts, sections and measurements, the compare | fast |
| L1 golden | `golden` | Every zoo document against its `.expected.json`; determinism | fast |
| L2 round-trip | `roundtrip` | Edit ops on zoo files: minimal diff, comments kept, reparse equals the tree, property-based op sequences | fast |
| L3 solver | `solver` | Sketch constraints and mates: known solutions, degrees of freedom, redundancy and conflicts, drag, perturbed starts, timing | fast |
| L4 references | `refs` | Every selector in the zoo parts under parameter and dimension changes; dangling references | medium |
| L5 API | `api` | FastAPI test client, a live uvicorn server with a WebSocket and the file watcher, the MCP tools | medium |
| L6 CLI | `cli` | Commands in-process through typer's runner, plus one real subprocess | medium |
| L7 IO | `io` | STEP export and import, STL, SVG, DXF and PDF, DXF import, the vendor generators | medium |
| L8 render | `render` | Offscreen PNGs through VTK; skipped loudly without pyvista | slow |
| client state | none, `npm test` | The real TypeScript store under `node:vm` with the API and React mocked | fast |
| L9 browser | none, `web/verify.mjs` | Playwright driving real Chromium against a served bundle | slow |
| L10 corpus | `corpus` | Real vendor STEP files from an untracked local directory; skipped when absent | slow |
| L11 performance | `perf` | Budgets per zoo document in CI; the recorded baseline on request | medium |
| L12 agent | `agent` | A scripted session builds the bracket through the CLI and the MCP tools | slow |

## The zoo as fixtures

Each zoo document has a sibling `.expected.json` with golden values:

```json
{
  "volume": 16203.097396,
  "area": 9599.743257,
  "bbox": {"min": [-30.0, -40.0, 0.0], "max": [30.0, 0.0, 50.0], "size": [60.0, 40.0, 50.0], "center": [0.0, -20.0, 25.0]},
  "counts": {"solids": 1, "faces": 20, "edges": 54, "vertices": 36},
  "center_of_mass": [-11.711181, -20.0, 12.343375],
  "mass": 43.748363,
  "features": {"profile": {"faces_created": 0}, "body": {"faces_created": 8}}
}
```

A drawing's golden file holds the sheet, each view's segment counts,
references and extents, and every dimension's kind, value and text.
`uv run pytest --update-golden` rewrites the files; the diff is reviewed like
code. Vendor parts are stand-ins generated by `zoo/vendor/gen_*.py`; a test
regenerates and compares them, so the STEP files never drift. Real vendor
files live in `corpus/` (gitignored) and feed only L10 and the bench script.

## Tolerances

| Quantity | Tolerance |
|---|---|
| Volume, area, mass | relative 1e-6 for golden values and STEP round trips; an imported vendor body absolute 1 mm³ |
| Bounding box, centre of mass, measurements, dimension values | absolute 1e-4 mm; drawing view extents 1e-3 mm |
| Sketch solve | residual below 1e-9 on the fixtures, below 1e-8 from perturbed starts |
| Assembly poses | position 1e-6 mm, angles 1e-6 degrees, the analytic Jacobian within 1e-6 of finite differences |
| Render | the image has the requested size, is not blank, and a highlight changes pixels |
| Performance | CI uses the fixed budgets under L11. Against the recorded baseline, fail when a number exceeds it by more than thirty percent plus 0.02 s of timer slack; thirty previews in a row may not grow the process's peak memory by more than fifteen percent |

## What each layer asserts

- **L0 unit.**
  - Parsing: every DSL call becomes a feature with the right kind, arguments,
    source text and span; loop features are read-only; errors report a line.
  - Features: directions, drafts, nested profiles, a failed feature skipped
    while downstream continues, rollback and suppression, semantic labels
    surviving every feature kind, the prefix cache, offsets, planes.
  - Selectors and compare: selector text parses like the file; ids on parts,
    sectioned parts and posed instances; added and removed volume against a
    file or a git revision; sections keep one side with cap faces.
  - Mesh: the binary encoding round-trips with face and edge ids; an assembly
    tessellates each product once and places instances by transforming the
    arrays, so moving an instance tessellates nothing new.
  - Reliability (`test_reliability.py`, on temporary files): an external
    write is detected before the watcher fires and rechecked before a
    replace; a failed replace, undo or redo keeps file, memory and history;
    an edit during evaluation cannot publish old geometry; dependency changes
    reach assemblies, drawings, meshes, queries and comparisons, even when
    they land mid-evaluation; a malformed sidecar is ignored with a warning.
  - Contracts (`test_contracts.py`, on scratch files): generated source with
    quotes, backslashes, control characters and Unicode round-trips; invalid
    operations and batches get HTTP 422 with a readable error before any
    write; older statement and tuple clients keep working; OpenAPI describes
    every edit variant; `web/src/api/operations.ts` matches the generator.
    Envelopes live in `operations.py`; failed edits give 400, stale hashes 409.
- **L1 golden.** Every field of each document's `.expected.json` is compared;
  the bracket evaluated twice gives the same volume and encoded mesh.
- **L2 round-trip.** Per zoo file and op kind: minimal diff, every comment
  survives, the reparsed tree equals the in-memory tree, the text matches
  what a person writes, the geometry changes as expected. Hypothesis runs
  sequences of up to six valid ops on the bracket; the file parses after
  every step and keeps its comments. Sketch write-back touches only literals,
  and a drag diff stays on the dragged entities.
- **L3 solver.** One fixture per constraint kind; the Jacobian matches finite
  differences; degrees of freedom equal the known number; redundant and
  conflicting constraints are named; drag moves only the free variables;
  twenty starts jittered by up to twenty percent agree; ten solves average
  under fifty milliseconds. Mates: each kind reaches its known pose, drag
  follows free motions, conflicts are reported, twelve perturbed starts agree.
- **L4 references.** Every parameter and dimension of every zoo part is
  nudged by eight percent and every stored selector must still resolve to
  the same entities; click selectors survive a dimension change. A
  deliberately broken reference errors on its own line while the body builds.
- **L5 API.** `test_api.py`: open and tree, stale-hash rejection, undo and
  redo with their events, source PUT with error reporting, mesh, query,
  render, export, measure, views, STEP wrappers, new documents, previews that
  write nothing, selectors by text. All kernel work runs on one worker
  thread: two documents evaluating at once never overlap. `test_live_server.py`
  runs real uvicorn; an external edit reaches the WebSocket. `test_mcp.py`:
  every tool in-process, plus one real stdio session. Assemblies, drawings
  and editable imports: tree queries, pose write-back, the dependency refresh
  event, preview and drag, drawing edits and export, close, make editable.
- **L6 CLI.** Commands run through typer's runner and print JSON the test
  parses: tree, query, edit with dry run, export, mesh, render, new, measure,
  compare, docs, assemblies, drawings. One real subprocess; errors exit non-zero.
- **L7 IO.** The bracket re-imports from STEP with the same volume and
  bounding box; an assembly round-trips names, colours and poses; import
  reports hierarchy, names, colours and positions, caches by path, mtime and
  size, and enforces one solid per part. STL is binary with a triangle count
  matching the file size. The bracket drawing exports to SVG, DXF and PDF.
  `test_dxf.py` reads DXF files into sketches (units, bulges, blocks,
  splines, layers, joined ends and reported gaps), solves and converts the
  rigid import, rebuilds when the file changes, draws a DXF view on a sheet
  with no model and exports it, and opens a DXF as a part or a drawing
  through the API.
- **L8 render.** The bracket renders from the iso and top views at the
  requested size, the image is not blank, highlighting every face changes
  pixels, an unknown view raises. The module skips when pyvista is missing.
- **Client state.** `web/tests/state.test.mjs` compiles the real store with
  the `typescript` package, links it under `node:vm` with `react` and the
  API module replaced by synthetic modules, and controls the timers. Failed
  saves keep the draft; closing saves first and stays open after a failure;
  typing during a save drains the newest text in order; an external change
  becomes a conflict that typing cannot overwrite; late responses cannot
  overwrite a newer tab; a dependency event refreshes meshes and queries;
  previews coalesce (one in flight, only the newest change waits) and
  clearing the preview drops the waiting change too.
- **L9 browser.** `web/verify.mjs` launches full Chromium
  (`channel: 'chromium'`) and runs more than a hundred checks against a
  served scratch copy of the zoo, reading the file on disk after every edit:
  picking, property and parameter edits, undo, feature dialogs with previews,
  cascade delete, sketch mode, external edits, snapshot, the compare overlay,
  context menus, assemblies, sections, measurements, named views, STEP
  viewing, a sub-assembly in a tab of its own, make editable, tabs, the
  drawing sheet, panel layout, and no console errors. Screenshots land in `web/*.png` for inspection only. It
  exits 1 on any failed check.
- **L10 corpus.** Every STEP file in `corpus/` imports with unique instance
  paths, wraps into a document that evaluates and meshes, sections at three
  offsets with caps, and measures two faces named in `corpus/manifest.json`.
- **L11 performance.** CI budgets in `tests/test_perf.py`: warm evaluation
  under 1 s for the bracket and the lid, 2 s for the enclosure and the node
  review, 3 s for the node assembly; meshing under 1.5 s; sketch solves under
  50 ms; a tail edit with the prefix cache under half a full evaluation; the
  bracket drawing under 1 s. `scripts/bench.py` measures, per zoo document
  and for a generated stress assembly of sixty instances: cold open, warm
  re-evaluation, a warm edit with its mesh, a preview (median of three), the
  mesh cold and warm, and peak memory; then thirty previews in a row for
  memory growth; the local corpus assembly when present, printed but never
  recorded. `--record` rewrites `tests/perf_baseline.json` (one laptop's
  numbers); `--check` exits 1 on a regression. The strict pytest run applies
  the same comparison and skips without `PLAINSOLID_PERF_STRICT`.
- **L12 agent.** `tests/test_agent.py` builds the zoo's bracket from an empty
  file through the CLI and through the MCP tools and checks the golden
  numbers and that the statements are exactly `zoo/bracket.py`'s. A wrong
  selector fails its feature on its line and undo removes it.

## CI

`.github/workflows/ci.yml` runs on pushes to `main` and on pull requests:
two jobs on `ubuntu-latest`, thirty minutes each, with `uv sync --frozen`
behind the uv cache and Node 24 behind the npm cache. Both install
`libopengl0 libgl1 libegl1 libxrender1` so the stock VTK wheel renders
offscreen without a display. Neither job runs the corpus layer or the
baseline comparison.

- `test`: the fast subset, then `uv run pytest -m "not corpus"`, then
  `cd web && npm ci && npm test && npm run build` (`tsc` type-checks and the
  bundle lands in the Python package). On failure it uploads the `renders`
  artifact: every PNG under pytest's temp directory.
- `browser`: `npm ci && npm test && npm run build`, Playwright's Chromium
  with its system dependencies, the zoo copied to `/tmp/proj` and served by
  `uv run plainsolid serve /tmp/proj --port 8399`, a wait on `/api/health`,
  `bracket.py`, `node_review.py` and `node.py` opened through the API, then
  `node verify.mjs http://127.0.0.1:8399/ /tmp/proj`, failing on any `FAIL`
  line. On failure it uploads the `browser` artifact: `web/*.png`, the server
  log and the verify log.

## Conventions

- One layer marker per test; an unmarked test fails collection.
  `pytest-timeout` caps every test at 300 s.
- Shared fixtures live in `tests/conftest.py`: `zoo_dir`, `project` (a
  scratch copy of the zoo), `bracket_src`, `bracket_eval`, `update_golden`.
- Zoo documents under `zoo/`, expected values next to their document, vendor
  STEP files and generators under `zoo/vendor/`.
- Test names describe the behaviour, not the function.
- Adding a zoo document: write it, run `uv run pytest --update-golden`,
  review the numbers against an independent estimate, commit both.
- A test that needs a machine capability (pyvista, the corpus directory, the
  strict performance variable) skips with a message naming it, never silently.
- After changing an edit contract, run `scripts/generate_edit_types.py`,
  then `cd web && npm test && npm run build`. The state module's
  responsibilities are in [`web/src/state/README.md`](../web/src/state/README.md).
